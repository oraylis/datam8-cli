# DataM8 CLI 2.1.0

This release adds local model maintenance for automation and agents, while retaining
the existing solution format and synchronous generation.

## Model maintenance and automation

- Create, update, delete, clone, rename and move entities, including targeted nested
  edits and selection of existing Base collection files.
- Discover schemas, inspect solutions and plugins, import and refresh sources, and
  manage transformation source files without a running HTTP server.
- Use compact UTF-8 JSON responses, JSON files or stdin, consistent exit codes and
  ordered batches. Each completed batch operation is saved; execution stops at the
  first failure without rolling back earlier saves.
- Check secret availability and set secrets through stdin without displaying their
  values. The former `secrets show` command has been removed. Use `secrets check`
  for availability or `sources test-connection` to verify a connection.

## Fixes and backend improvements

- Preserve existing Base collection placement when creating items, and persist new
  folder metadata inside its owning folder.
- Prefer an explicitly selected CLI solution over environment defaults.
- Generate successfully to internal, parent-relative and absolute output paths.
  Generation failures produce structured JSON errors and retain completed-operation
  receipts in failed batches, including target, template and module-loading errors.
- Support safe desktop workspace switching through the existing backend process,
  reject stale writes and reload workspace-owned modules. Failed switches retain
  the previous workspace and its plugin registry.
- Publish tested wheel and source archives through an explicit protected-tag
  release workflow with a required CI result.

## Compatibility

The schema version remains **2.0.0**. Machine-readable CLI output is now normalized
to success/error envelopes and compact entity summaries; scripts consuming older
JSON output must adapt. Human-readable commands remain available, except for the
removed secret-display command. Batches are not transactions.

See the [agent CLI contract](../cli-agent-contract.md), the
[backend contract](../backend-contract.md) and [release process](../ci.md).
