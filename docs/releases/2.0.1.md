# DataM8 Generator 2.0.1

- Read and write solution, Base and Model JSON as UTF-8 on every platform.
- Write generated text and v1 migration output as UTF-8, preserving umlauts and
  other Unicode characters through import, refresh, save and reload.
- Open existing Windows-1252 solutions by converting affected JSON files to
  UTF-8 before loading. Conversion preserves formatting, uses atomic replacement
  and leaves no backup files. UTF-8 and ASCII files remain unchanged.

The schema version remains **2.0.0**. Plugins, templates, transformation Python
files and existing output are outside the automatic JSON conversion. Text that
was already corrupted inside valid UTF-8 is not automatically repaired.
See the [canonical backend contract](../backend-contract.md) for conversion scope.
