# DataM8 CLI 2.1.3

- `secrets set`, `check`, `add`, and `unset` accept both `datasources/…` and
  `ref://datasources/…`. Both forms use the same keyring entry as a data source
  configured with the reference.
- Saving after a folder deletion removes parent directories that become empty
  during cleanup. Files and directories with remaining content are preserved.
  See [PR #56](https://github.com/oraylis/datam8-cli/pull/56).

## Previously stored secrets

If a previous CLI stored a secret under `ref:/datasources/…`, set the value again
under `datasources/…` or `ref://datasources/…` with `secrets set PATH --file -`.
Confirm it with `secrets check PATH`, then remove the old entry with
`secrets unset 'ref:/datasources/…'`, using the exact path shown by
`secrets list`.

See the [release process](../ci.md).
