# DataM8 CLI 2.1.2

This patch release preserves omitted expression languages when model entities are
edited and saved.

## Compatibility and release

The solution schema version remains **2.0.0**. Attributes without an explicit
`expressionLanguage` stay without that field after an edit; explicit language
values remain unchanged. The schema default is removed in the DataM8 Model 2.0.1
revision pinned by this release.

After merging the release PR into main, push the protected tag `v2.1.2` at the
merged commit. The release workflow verifies the version, runs CI and publishes
the tested wheel and source archive to GitHub Releases. It does not publish to PyPI.

See the [backend contract](../backend-contract.md) and [release process](../ci.md).
